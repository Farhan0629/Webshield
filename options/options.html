WebShield AI — Settings

Add a free Google Safe Browsing API key for ground-truth threat checks alongside local heuristics.

The key is stored locally in this browser (chrome.storage.local) and is only ever sent directly from your browser to safebrowsing.googleapis.com. Without a key, WebShield AI still runs on local heuristics alone — Safe Browsing checks are simply skipped.
How to get a free key (~2 minutes, no billing required)
  1. Go to the Google Cloud Console and create (or pick) a project.
  2. Open APIs & Services → Library, search for "Safe Browsing API", and click Enable.
  3. Open APIs & Services → Credentials → Create Credentials → API key.
  4. Copy the generated key and paste it above.
